# Authority Review Workflow

## Purpose

Authority review resolves structural uncertainty discovered during migration and candidate evaluation.

Curator decision is always authoritative.

## Ordered Workflow

1. Grove check.
2. Composer source review.
3. MusicBrainz Work search.
4. MusicBrainz relationship review.
5. Recording/Release matching.
6. Wikipedia fallback.
7. Curator decision.

## Rules

- Never auto-select among competing Work identities.
- Never auto-accept candidate performances.
- Use authority sources as evidence, not as automatic truth import.
- Keep unresolved items in review artifacts until curator decision.

## Evidence Record

Each reviewed candidate should retain:

- source file and line,
- proposed Work assignment,
- authority evidence summary,
- decision rationale,
- final status.

## Decision Outcomes

- Accept: promote to canonical Work/Performance structures as appropriate.
- Reject: keep traceability in reports/issues.
- Supersede: link prior candidate and replacement rationale.
