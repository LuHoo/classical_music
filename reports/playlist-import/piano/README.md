- Known independent arrangements have specific Works, reusing the family when it exists. Scharwenka/Beethoven interpretations reuse the existing arrangement Works. Orchestral Ravel/Grieg recommendations are not replaced by solo versions.
- Non-adjacent movements are gathered into their Work, including Debussy, Busoni and Poulenc. All source positions remain intact; selected opening movements supply listening links when they occur later in the playlist.
- Debussy’s first Arabesque appears twice as different release IDs with the same ISRC. Both occurrences belong to the same interpretation; this is not a musical choice.
- Excerpts are explicit, including the lone Bach–Busoni Toccata and the incomplete selection from Dohnányi’s Suite en valse. Unselected album tracks are not imported.
- Three erroneous legacy Brahms opus-set titles (117, 118, 119) and their family titles are corrected using the label track list. Stable IDs, performers and existing recommendation links are preserved.
- Exact trusted tracks or a reviewed same-release anchor plus compatible Work identity support reuse. Legacy anchors sometimes point to another Work on the same album; those links are not rewritten here.
- Usage rules for NL are retained as catalogue evidence; playback was not tested. No publication or merge is performed by this import.
